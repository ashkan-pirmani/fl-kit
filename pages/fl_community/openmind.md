# OpenMined Community

- **URL:** [https://www.openmined.org/](https://www.openmined.org/)
- **Description:** OpenMined is a global open-source community focused on privacy-preserving machine learning, including federated learning. It provides education, tools, and collaboration opportunities for privacy-enhancing technologies.
- **Access Details:** Open, with Slack and GitHub for collaboration; free to join.
- **Focus:** Privacy-preserving machine learning, federated learning, secure computation.
- **Interaction Style:** Real-time (Slack), asynchronous (GitHub, forums), event-based (workshops, webinars).
- **Additional Notes:** Offers educational courses, active development, and a large, diverse membership. Great for those interested in both research and practical applications of FL and privacy tech.
